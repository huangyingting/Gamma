## 2. REST API Specification

### 2.1 Authentication, Invitations & Governance APIs
- `POST /api/auth/[...nextauth]` — NextAuth v4 Credentials endpoint with live DB status/role check.
- `GET /api/invitations/verify?code=...` — Validates an invitation code and returns `{ valid, invitation: { invitedEmail, role, expiresAt, status }, reason? }`.
- `POST /api/auth/register` — Redeems a valid invitation code inside a serializable transaction and creates the `ACTIVE` user account.
- `GET /api/invitations` (`ADMIN`) — Lists all invitations with status reconciliation (`EXPIRED` auto-computed when `expiresAt <= now`).
- `POST /api/invitations` (`ADMIN`) — Creates a single-use invitation (`invitedEmail`, `role`, `expiresInDays`) and logs `INVITATION_CREATED`.
- `PATCH /api/invitations/[id]` (`ADMIN`) — Revokes a pending invitation and logs `INVITATION_REVOKED`.
- `GET /api/admin/users` (`ADMIN`) — Lists all registered users and their current `role` and `status`.
- `PATCH /api/admin/users/[id]` (`ADMIN`) — Updates a user's `role` (`ADMIN`, `EDITOR`, `VIEWER`) or `status` (`ACTIVE`, `REVOKED`), enforcing self-protection rules and logging `USER_ROLE_UPDATED` / `USER_STATUS_UPDATED`.
- `GET /api/admin/audit-logs` (`ADMIN`) — Returns filterable chronological `AuditLog` entries.

### 2.2 Workspace, Decks, Cards & AI APIs
- `GET /api/workspace/summary` — Returns workspace folders, active themes, recent decks, and current user permissions.
- `GET /api/docs` — Lists workspace decks with optional filters (`filter=all|recent|mine|favorites|trash`, `folderId`, `search`).
- `POST /api/docs` (`ADMIN`/`EDITOR`) — Creates a new blank or seeded Gamma deck.
- `GET /api/docs/[id]` — Fetches a deck with ordered `cards`, `theme`, `folder`, `owner`, and `comments`.
- `PATCH /api/docs/[id]` (`ADMIN`/`EDITOR`) — Updates deck metadata (`title`, `themeId`, `folderId`, `isFavorite`, `isPublic`, `workspaceAccess`, `archivedAt`), or replaces/reorders `cards`.
- `DELETE /api/docs/[id]` (`ADMIN`/`EDITOR`) — Permanently deletes a trashed deck.
- `POST /api/docs/[id]/duplicate` (`ADMIN`/`EDITOR`) — Deep-clones a deck and all its cards.
- `POST /api/docs/[id]/cards` (`ADMIN`/`EDITOR`) — Inserts a new card at `orderIndex` (blank, smart-layout, or AI-generated).
- `PATCH /api/docs/[id]/cards/[cardId]` (`ADMIN`/`EDITOR`) — Updates card title, `layoutAccent`, `accentImageUrl`, `backgroundColor`, `fullBleed`, `contentAlignment`, `speakerNotes`, or `blocksJson`.
- `DELETE /api/docs/[id]/cards/[cardId]` (`ADMIN`/`EDITOR`) — Removes a card and normalizes remaining `orderIndex` values.
- `POST /api/docs/[id]/comments` — Adds or resolves a comment on a deck/card.
- `POST /api/ai/outline` (`ADMIN`/`EDITOR`) — Generates a structured multi-card outline from a prompt, pasted text, imported content, or template.
- `POST /api/ai/generate-deck` (`ADMIN`/`EDITOR`) — Synthesizes a complete multi-card `Doc` with rich `CardBlock[]` layouts (`stat_grid`, `smart_layout`, `chart`, `timeline`, `callout`, `table`), accent images, and speaker notes from an outline + theme.
- `POST /api/ai/agent` (`ADMIN`/`EDITOR`) — Executes a conversational **Gamma 5 AI Agent** instruction on the active deck or card (rewriting content, adding charts/smart layouts, inserting cards, or restyling) and persists the updated card state.
- `GET / POST / DELETE /api/folders` — CRUD for workspace folders.
- `GET / POST / PATCH /api/themes` — CRUD for standard and custom workspace themes.
- `GET / POST /api/templates` — Lists templates and instantiates a new `Doc` from a template (`POST /api/templates/use`).
- `GET / POST / DELETE /api/ai-images` — Lists and generates AI media assets (`POST /api/ai-images`).
- `GET / POST / PATCH / DELETE /api/sites` — Converts a `Doc` into a published `Site`, updates `customDomain` / `status`, or unpublishes.

## 3. Phased Implementation Plan

1. **Phase 1: Project Scaffolding & Dual-DB Prisma Setup (`scaffold-db-auth`)**
   - Initialize `package.json`, `tsconfig.json`, Next.js 16 config, Tailwind CSS v4, and Prisma 7 schemas (`prisma/schema.prisma` for SQLite and `prisma/schema.postgres.prisma` for PostgreSQL).
   - Implement `src/lib/prisma.ts`, `src/lib/account-admission/*`, NextAuth configuration (`src/lib/auth.ts`), and `scripts/bootstrap-admin.ts`.
   - Create `prisma/seed.ts` to populate standard themes (`Prism`, `Stratos`, `Aurora`, `Obsidian`, `Founder`, `Sage`), flagship decks (including *"Your Roadmap to Success"*, *"GenesisIQ Series B Pitch Deck"*, *"Q3 Engineering Architecture & AI Agent Roadmap"*), folders (`Engineering & Strategy`, `Executive & Board`), templates across all 12 categories, AI images, a published Gamma Site (`roadmap.genesisiq.ai`), sample invitations, and audit logs.
2. **Phase 2: Core Backend Route Handlers & Admission Guards (`implement-gamma-app`)**
   - Build all `/api/**` route handlers with strict authentication, `ACTIVE` status verification, RBAC (`ADMIN` / `EDITOR` / `VIEWER`), and audit logging.
3. **Phase 3: Gamma 5 Frontend Surfaces (`implement-gamma-app`)**
   - Implement Public Marketing (`/`), Pricing (`/pricing`), Sign-in (`/signin`), Invite-Only Registration (`/signup`), Forgot Password (`/forgot-password`).
   - Implement the 2-Tier Workspace Shell and all workspace hubs (`Gammas` Grid & List views, `Folders`, `Sites`, `AI Images`, `Templates`, `Themes`, `Trash`, `Settings & Members` + Admin Governance & Audit Console).
   - Implement all 4 AI Creation Studio flows (`/create`, `/create/generate`, `/create/paste`, `/create/import`, `/create/from-template`).
   - Implement the full Gamma 5 Collaborative Card Editor (`/docs/[id]`), Public Viewer (`/public/[slug]`), and Published Site Renderer (`/s/[siteSlug]`).
4. **Phase 4: Build, CLI Bootstrap & End-to-End Playwright Verification (`verify-and-test`)**
   - Run database migrations, seed script, `npm run bootstrap:admin`, `npm run build`, and comprehensive Playwright E2E test suite verifying all user journeys, invite-only admission rules, role restrictions, revocation enforcement, AI creation flows, card editor tools, and mobile responsiveness.
