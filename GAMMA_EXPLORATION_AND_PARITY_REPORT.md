## 4. Invite-Only Account Admission & Security Architecture

In accordance with the project requirements and `../Arcade/docs/NEXTAUTH_INVITE_ONLY_SPEC.md`, our application augments Gamma's workspace architecture with a strict **Invite-Only Account Admission, Role, Revocation, CLI-Only Admin Bootstrap, and Immutable Audit Log** subsystem:

1. **No Public Open Signup**: Self-service registration requires a valid, unrevoked, unexpired, single-use `Invitation` token (`code`) whose `invitedEmail` matches the normalized user email (`trim().toLowerCase()`).
2. **CLI-Only Admin Bootstrap (`npm run bootstrap:admin`)**: No HTTP endpoint exists for bootstrapping the initial administrator. The `scripts/bootstrap-admin.ts` CLI script reads `ADMIN_EMAIL`, `ADMIN_PASSWORD`, and `ADMIN_NAME` from environment variables and idempotently upserts the initial `ADMIN` user and default workspace.
3. **Database Re-Validation on Every Session Check**: Every NextAuth JWT/session callback re-queries Prisma by `user.id` to verify `user.status === 'ACTIVE'` and fetch the live `user.role` (`ADMIN`, `EDITOR`, `VIEWER`). Setting a user's status to `REVOKED` immediately invalidates their active session on the very next request.
4. **Transactional Single-Use Invitation Redemption**: Registration executes inside `prisma.$transaction(...)` with an atomic `updateMany` guard (`WHERE id = invitation.id AND status = 'PENDING' AND acceptedAt IS NULL AND expiresAt > now`), preventing race conditions or double-redemption.
5. **Comprehensive Audit Trail (`AuditLog`)**: Every security-sensitive event (`ADMIN_BOOTSTRAPPED`, `INVITATION_CREATED`, `INVITATION_REVOKED`, `INVITATION_REDEEMED`, `REGISTRATION_REJECTED`, `LOGIN_SUCCEEDED`, `LOGIN_REJECTED`, `USER_ROLE_UPDATED`, `USER_STATUS_UPDATED`) is recorded in the `AuditLog` table and surfaced in the Admin Governance Console (`/settings/members` & `/admin/access`).
